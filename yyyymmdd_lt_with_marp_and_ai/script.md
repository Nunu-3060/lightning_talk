# 台本

## 表紙

* 挨拶
* 自己紹介
  * 本職はテストエンジニア。
  * スライド作成は得意ではない。
* 今日は LT の資料の作り方の話をする。

## 目次

* 全体の流れ
  * Marp の紹介、作り方、やってみた結果と失敗の順に話す。

## 3

* 以前の LT「お絵描き matplotlib」も Marp で書いた。
* ただし構成・文章・図・体裁の調整はすべて自分でやった。
* 1 本に数日以上かかっていた。

## 4

* 結論を先に言う。
  * Marp で書き、Claude Code に書かせ、人が決める。
* 今見ているこの資料も、この方法で作った。

## 5

* Marp の紹介
  * 左の Markdown が右のスライドになる。
  * 先頭の設定（front-matter）でテーマなどを決め、`---` でページを区切るだけ。
* 出力は HTML・PDF・PPTX。
* 自分で書くときは Marp for VS Code でプレビューしながら書く。

## 6

* なぜ Claude Code と相性が良いか
  * スライドがただのテキストなので、Claude Code がファイルを直接書ける。
  * marp-cli で画像に出力させれば、表示崩れを Claude Code 自身に確かめさせられる。
* 変更は差分で読めて、Git で管理できる。

## 7

* 流れの説明
  * 青い箱が自分の作業、枠線だけの箱が Claude Code の作業。
  * prompt.md で依頼し、result.md で報告させる。
  * 構成が決まるまで何度でもやり取りする。
  * 書かせた後も、確認して修正を依頼できる。

## 8

* 依頼は雛形 1 枚
  * 毎回書くのは題目・目的・対象オーディエンス・作業内容だけ。
  * 体裁や検査の条件は雛形に書いてあるので、毎回同じものが課される。

## 9

* いきなり書かせない。
  * まず構成案と確認事項を出させる。
* 例はこの LT の実際のやり取り。
  * Claude Code から「Claude Code と明記してよいか」と聞かれ、回答した。
* この LT は構成案のやり取りを 3 回してから執筆に入った。

## 10

* 体裁の条件も書いておく。
  * 常体、英数字の前後の空白、1 ページ 1 メッセージなど。
* 書いた後に marp-cli で全ページを画像に出力させ、はみ出しが無いか確かめさせる。

## 11

* 図はコードで描かせる。
  * この資料の流れ図や表紙の一覧も、Python と Graphviz のスクリプトで作った。
  * コードには flake8・mypy の検査も課している。
* スクリプトがあるので、直して実行し直せば何度でも作り直せる。

## 12

* 台本も一緒に書かせる。
  * 今話している内容も、元は Claude Code が書いた箇条書き。
* そのまま読むのではなく、手直しして自分の言葉で話す。

## 13

* 結果
  * 以前は数日以上かかっていたのが、依頼を書き始めてから確認が終わるまで 1 日以内になった。
  * 4 日間で 6 本作った。
* ただし 6 本のうち 2 本は没にした。次のページから、その話をする。

## 14

* 没 1：「仕事で使う Python」
  * 経験者向けに話したかったが、出来上がりは初心者向けの内容だった。
  * 対象オーディエンスには「経験年数は皆浅くない」と書いていた。
  * しかし目的が「紹介する」だけだったので、用途を一通り並べる構成になった。
* 教訓：聞き手を書くだけでは足りない。聞き手が何を持ち帰るかを目的に書く。

## 15

* 没 2：「AI 時代の技術者倫理」
  * 主張ははっきり書いていたが、経験のあるエンジニアにとっては当たり前の内容だった。
  * Claude Code は頼まれた主張をきれいに整えるが、面白いかどうかは判断しない。
* 教訓：聞き手にとって新しいかで目的を選ぶ。
* どちらも AI の誤りではなく、依頼の誤り。
  * 直さずに没にし、以降の LT の目的と対象オーディエンスの設定に生かした。

## 16

* 人がやること
  * 目的と聞き手を具体的に決める。
  * 構成案を聞き手の目で読む。
  * 自分の経験や実例を渡す。
  * 事実と URL を確かめる。
* 没にした 2 本も、構成案の段階で気付けたはずだった。

## 17

* まとめ
  * Marp はテキストなので、Claude Code にスライド・図・台本を一式書かせられる。
  * 雛形・構成案・体裁の条件で、1 本が 1 日以内に作れる。
  * 何を・誰に話すかは人が決める。
* 雛形を 1 枚書くところから始められるので、試してほしい。
